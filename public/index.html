Create an account or log back in. Your character is stored on the server, so it follows you to any device.

Multiplayer needs server.js running somewhere. Local: http://localhost:8000. Hosted: your Render/Railway URL. Static hosts like Netlify or GitHub Pages cannot run it.
The very first account created on this server becomes the admin. Admins can hand out admin with /admin <user>.
